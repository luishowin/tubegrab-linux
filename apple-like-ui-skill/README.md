# Apple-like UI style for small utilities

This folder is the repository copy of the global OpenCode skill at:

    ~/.config/opencode/skills/apple-like-ui/SKILL.md

It documents the light/dark palette, rounded antialiased Canvas controls,
compact responsive layout, segmented sliders, and Tk-specific pitfalls used for
TubeGrab's Apple-inspired interface. Keep the repository and global copies in
sync when either one changes.

To use it in OpenCode, the global copy is registered as skill ID
`apple-like-ui`.
